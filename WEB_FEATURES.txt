LearnShift AI Web Feature Overview
==================================

Project Purpose
---------------
LearnShift AI is a web-based adaptive learning prototype for Java Object-Oriented Programming.
The web app helps learners practice OOP concepts, receive adaptive explanations, request hints,
complete diagnostic and assessment flows, and gives educators evidence-based class analytics.

Main User Roles
---------------
1. Learner
   A learner can create or select a fictional learner profile, complete diagnostics, view mastery,
   study recommended concepts, ask the tutor for help, and take adaptive assessments.

2. Educator
   An educator can view class-level mastery, inspect learner progress, review alerts, see recurring
   misconceptions, and use recommended interventions.

Home Page Features
------------------
- Presents LearnShift AI as an adaptive Java OOP learning prototype.
- Provides navigation to:
  - Learner experience
  - Educator dashboard
  - Responsible AI disclosure
- Highlights judge-visible evidence:
  - Mastery changes after diagnostic and assessment attempts.
  - Adaptive teaching action changes based on learner state.
  - Grounded source references for explanations.
  - Educator alerts generated from stored interactions.

Learner Selection Features
--------------------------
- Lists existing learners with:
  - Display name
  - Current level
  - Overall mastery percentage
  - Recommended concept or diagnostic status
- Allows creation of a fictional learner.
- Supports starting levels:
  - BEGINNER
  - INTERMEDIATE
  - ADVANCED
- Provides a demo seed action to populate sample learners and data.
- Sends new learners directly into the diagnostic flow.

Diagnostic Flow Features
------------------------
- Starts an initial diagnostic for Java OOP concepts.
- Loads six diagnostic questions covering:
  - Classes and Objects
  - Encapsulation
  - Inheritance
  - Method Overloading
  - Method Overriding
  - Polymorphism
- Shows each question with:
  - Concept ID
  - Difficulty
  - Question type
  - Prompt
  - Options when available
- Records learner answer text.
- Records confidence from 1 to 5.
- Tracks approximate time spent per question.
- Submits diagnostic answers to the backend.
- Updates learner mastery and recommended starting concept.
- Redirects the learner to the dashboard after submission.

Learner Dashboard Features
--------------------------
- Displays learner profile information:
  - Display name
  - Current level
  - Overall mastery
  - Recommended next action
- Shows concept mastery cards for each OOP concept.
- Categorizes progress through mastery labels such as weak, developing, and mastered.
- Shows learner evidence:
  - Attempt count
  - Hint usage
  - Detected misconceptions
  - Last profile-changing reason
- Shows recent interactions in a timeline.
- Links to:
  - Run diagnostic
  - Start adaptive learning
  - Take adaptive assessment
  - Open tutor mode

Adaptive Learning Features
--------------------------
- Lets the learner choose an OOP concept or use the recommendation.
- Supports teaching actions:
  - Let LearnShift choose
  - Simplified explanation
  - Analogy
  - Step-by-step explanation
  - Java code example
  - Prerequisite review
  - Advanced application
- Sends learner ID, concept ID, and optional action to the backend.
- Backend can select a teaching action from learner evidence such as mastery, confidence,
  misconceptions, and hint usage.
- Displays:
  - Generated lesson response
  - Concept ID
  - Teaching action
  - Reason the action was selected
  - Quick guiding question
  - Source references from the academic OOP content

Tutor Mode Features
-------------------
- Lets the learner type a confusion, wrong answer, or Java OOP question.
- Records learner confidence from 1 to 5.
- Sends the message to the backend tutor endpoint.
- Backend detects the relevant concept and likely misconception.
- Displays:
  - Tutor explanation or reframe
  - Detected concept
  - Misconception bank item when found
  - Source references
- Designed to help learners correct misunderstandings without simply replacing teacher judgment.

Adaptive Assessment Features
----------------------------
- Lets the learner request the next adaptive question.
- Can use the learner recommendation or a selected concept.
- Displays:
  - Selected question
  - Concept ID
  - Difficulty
  - Question type
  - Options when available
  - Reason the question was selected
- Allows learner answer input.
- Records confidence from 1 to 5.
- Provides up to three progressive hints per question.
- Tracks hint count and includes it when submitting an answer.
- Submits answers to the backend for grading.
- Shows feedback after submission.
- Updates learner profile and mastery after attempts.
- Includes safeguard behavior for direct answer requests during assessment.

Educator Dashboard Features
---------------------------
- Displays class-level overview:
  - Learner count
  - Overall class mastery
  - Concept difficulty summary
- Lists learners with:
  - Display name
  - Current level
  - Overall mastery
  - Link to detailed learner evidence
- Shows concept-level analytics:
  - Concept ID and name
  - Average mastery
  - Number of weak learners
- Shows generated alerts.
- Shows recurring misconceptions with occurrence counts.
- Shows recommended educator actions.
- Provides a demo seed action to populate sample class data.

Educator Learner Detail Features
--------------------------------
- Displays an individual learner's profile.
- Shows recommended intervention for that learner.
- Shows concept mastery cards for all concepts.
- Displays a detailed evidence timeline.
- Displays learner-specific alerts and misconceptions.
- Helps educators review why the system recommended an intervention.

Responsible AI Disclosure Features
----------------------------------
- Explains model and API usage.
- Notes that Gemini can be used when GOOGLE_API_KEY is configured.
- Notes that deterministic grounded fallback responses are used when no API key is available.
- Lists frameworks and data sources:
  - FastAPI
  - SQLAlchemy
  - Alembic
  - MySQL or SQLite
  - Next.js
  - TypeScript
  - Tailwind CSS
  - OOP academic CSV chunks
  - Misconception bank
  - Hint ladders
  - Demo assessment records
- States privacy and safety limits:
  - Use only fictional or anonymized learners.
  - The app is not AGI.
  - The app is not a clinically validated cognitive profiler.
  - The app does not replace teacher judgment.
- Recommends human educator review before classroom use.

Grounded RAG and Source Reference Features
------------------------------------------
- The app is connected to a FastAPI backend that can retrieve from local OOP academic chunks.
- Explanations can include source metadata:
  - Source title
  - Chunk ID
  - Concept ID
  - Page number when available
  - Similarity or confidence score when available
- If Gemini is configured, the backend can use it for embeddings and generation.
- If Gemini is not configured, the backend falls back to deterministic grounded responses.
- The tutor and learning flows avoid unsupported topics outside the configured OOP module.

Backend API Integration Features
--------------------------------
- Frontend API base URL is controlled by NEXT_PUBLIC_API_BASE_URL.
- Default API URL is http://localhost:8000.
- Main frontend API areas include:
  - /api/demo/seed
  - /api/learners
  - /api/learners/{learner_id}/profile
  - /api/diagnostic/start
  - /api/diagnostic/submit
  - /api/teach
  - /api/tutor/confusion
  - /api/assessment/next
  - /api/assessment/submit
  - /api/hints/next
  - /api/educator/overview
  - /api/educator/alerts
  - /api/educator/learners/{learner_id}

Frontend Technology Features
----------------------------
- Built with Next.js App Router.
- Uses TypeScript for the web app.
- Uses Tailwind CSS for styling.
- Uses lucide-react icons.
- Uses reusable UI components for:
  - Concept mastery cards
  - Mastery progress bars
  - Recommendations
  - Source references
  - Educator alerts
  - Interaction timeline

Data and Evidence Features
--------------------------
- Stores learner profiles.
- Stores concept mastery.
- Stores diagnostic interactions.
- Stores assessment attempts.
- Stores hint usage.
- Stores misconception evidence.
- Stores educator alerts.
- Uses stored interactions to refresh recommendations and class analytics.

Supported Learning Concepts
---------------------------
- C001: Classes and Objects
- C002: Encapsulation
- C003: Inheritance
- C004: Method Overloading
- C005: Method Overriding

Typical Demo Flow
-----------------
1. Start the backend on http://localhost:8000.
2. Start the web app.
3. Open the home page.
4. Choose "Start as Learner".
5. Seed demo data or create a fictional learner.
6. Complete the diagnostic.
7. Review the learner dashboard.
8. Start adaptive learning or adaptive assessment.
9. Ask tutor mode about a misconception.
10. Open the educator dashboard to review analytics, alerts, and interventions.

Value of the Web App
--------------------
The web app demonstrates a complete adaptive learning loop:
- Collect learner evidence.
- Update mastery.
- Detect weak concepts and misconceptions.
- Recommend the next action.
- Provide grounded lessons and tutor feedback.
- Offer hints and adaptive assessments.
- Surface evidence and alerts to educators.
