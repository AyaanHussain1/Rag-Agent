# Java OOP Foundations: Classes and Objects

This reviewed prototype source explains the foundation of Java object-oriented programming. A class is a programmer-defined blueprint that names fields and methods. An object is a runtime instance created from that blueprint, usually with the `new` keyword. Constructors initialize object state when the object is created. Instance fields belong to each object, while static members belong to the class.

Learners often confuse a class declaration with an object. The declaration `class Student { }` defines the type, but `Student s = new Student();` creates an object reference and object instance. Understanding this distinction supports later topics such as encapsulation, inheritance, overriding, and polymorphism.
