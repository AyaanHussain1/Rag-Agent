# Demo Script

1. Start backend and frontend.
2. Open `/learner` and click **Seed demo data**.
3. Select `Demo Learner A - Beginner`.
4. Open the dashboard and point out weak concepts, hint count, misconceptions, and recommendation.
5. Go to `/learn`; teach Method Overriding or the recommended concept.
6. Select `Demo Learner B - Advanced`; teach the same concept and show the advanced teaching action.
7. Go to `/assessment`; request a question, use hints, submit an incorrect answer, and show mastery/evidence updates.
8. Type `just give me the answer` during assessment and show the safeguard response.
9. Go to `/tutor`; enter a confusion such as “overriding is two methods with different parameters” and show the misconception-focused reframe.
10. Open `/educator`; show low mastery, repeated misconception, low confidence, excessive hint usage, repeated incorrect attempts, and advanced learner alerts.
11. Open an educator learner detail page and show timeline evidence behind profile changes.
12. Use `/api/rag/answer` or learning page with an out-of-scope question such as database normalization and show the responsible refusal.
