# Live Demo Script

1. Open home page.
2. Start as learner.
3. Seed demo data.
4. Pick beginner learner.
5. Show profile and recommendation.
6. Run diagnostic or show diagnostic result.
7. Teach same concept to beginner learner.
8. Switch to advanced learner and teach same concept.
9. Show different teaching action/reason.
10. Take adaptive assessment.
11. Give incorrect answer.
12. Request progressive hints.
13. Submit answer after hints.
14. Show mastery/profile changed.
15. Open tutor mode and enter misconception.
16. Show reframe, guiding question, follow-up check, and source references.
17. Open educator dashboard.
18. Show alert and evidence.
19. Open safeguard demo.
20. Ask out-of-scope question.
21. Ask direct answer request during assessment.
22. Open disclosure page.

Recommended seeded learners:

- `demo_beginner`: weak prerequisite knowledge and high hint needs.
- `demo_confident_wrong`: confident but incorrect learner.
- `demo_repeater`: repeated overriding/overloading misconception.
- `demo_fast_careless`: mostly strong, with careless high-confidence mistakes.
- `demo_advanced`: advanced learner ready for challenge tasks.
