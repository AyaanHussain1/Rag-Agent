# AI Disclosure

LearnShift AI may use Google Gemini for embeddings and text generation when `GOOGLE_API_KEY` is configured. The prototype can also run without the key by using deterministic responses grounded in retrieved local OOP content.

The frontend uses Next.js, TypeScript, and Tailwind CSS. The backend uses FastAPI, SQLAlchemy, Alembic, MySQL, pandas, NumPy, and scikit-learn.

Data sources are the provided OOP academic chunks, concept CSV, misconception CSV, hint ladder CSV, and clearly labeled demo records.

Only fictional or anonymized learners should be used. This project is not AGI, not a clinically validated cognitive profiler, and not a substitute for educator review.

Human review workflow: teachers should inspect generated explanations/questions, verify source references, and use dashboard evidence before acting on interventions.
